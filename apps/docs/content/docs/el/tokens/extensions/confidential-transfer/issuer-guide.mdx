# Έκδοση Token Εμπιστευτικής Μεταφοράς στο Solana

Αυτός ο οδηγός απευθύνεται σε **εκδότες**: ομάδες που δημιουργούν και
διαχειρίζονται ένα mint Token-2022 που χρησιμοποιεί την επέκταση Εμπιστευτικής
Μεταφοράς. Καλύπτει τις αποφάσεις που λαμβάνετε κατά τη δημιουργία του mint και
τις λειτουργίες που εκτελείτε κατά τη διάρκεια ζωής του mint. Για τη ροή από την
πλευρά του κατόχου (κατάθεση, εφαρμογή, μεταφορά, ανάληψη) δείτε τις αναλυτικές
σελίδες, και για την υποστήριξη αυτών των token σε ένα προϊόν δείτε τον
[Οδηγό Ενσωμάτωσης](/docs/tokens/extensions/confidential-transfer/integration-guide).

Οι εμπιστευτικές μεταφορές διατηρούν τα ποσά μεταφοράς και τα υπόλοιπα
λογαριασμών κρυπτογραφημένα, ενώ αφήνουν τις διευθύνσεις λογαριασμών, το mint
και τους ιδιοκτήτες δημόσια ορατούς. Βασίζονται στο ZK ElGamal Proof Program για
επαλήθευση αποδείξεων onchain, επομένως το mint μπορεί να χρησιμοποιηθεί σε
clusters όπου αυτό το πρόγραμμα είναι ενεργοποιημένο.

## Αποφάσεις που λαμβάνετε κατά τη δημιουργία

Η επέκταση Confidential Transfer πρέπει να αρχικοποιηθεί πριν από την
αρχικοποίηση του mint και δεν μπορεί να προστεθεί αργότερα. Κατά τη δημιουργία
αποφασίζετε:

- **Πολιτική έγκρισης**: εάν οι λογαριασμοί μπορούν να επιλέξουν εμπιστευτικές
  μεταφορές χωρίς άδεια (`auto`) ή πρέπει να εγκριθούν από την αρχή
  εμπιστευτικής μεταφοράς του mint (`manual`).
- **Ελεγκτής**: εάν θα οριστεί ένα global ElGamal pubkey ελεγκτή ώστε ένα
  καθορισμένο μέρος να μπορεί να αποκρυπτογραφεί κάθε ποσό μεταφοράς για το
  mint. Προαιρετικό και μπορεί να αλλαχθεί αργότερα.
- **Προαιρετικές συνοδευτικές επεκτάσεις**: εμπιστευτικές χρεώσεις μεταφοράς (σε
  συνδυασμό με την επέκταση χρέωσης μεταφοράς) και εμπιστευτικό mint/burn, και
  τα δύο καλύπτονται παρακάτω. Αυτά επίσης πρέπει να αρχικοποιηθούν κατά τη
  δημιουργία.

## Δημιουργία εμπιστευτικού mint

Το CLI ορίζει την πολιτική έγκρισης με `--enable-confidential-transfers auto` ή
`manual`· το `auto` επιτρέπει σε οποιονδήποτε κάτοχο να διαμορφώσει τον δικό του
λογαριασμό, ενώ το `manual` θέτει αυτό υπό την έγκριση από την αρχή
εμπιστευτικής μεταφοράς (η οποία εκ προεπιλογής είναι η αρχή mint). Τα μονοπάτια
του client λαμβάνουν τις ίδιες ρυθμίσεις μέσω των παραμέτρων
`ConfidentialTransferMint`: μια αρχή, τη σημαία αυτόματης έγκρισης και ένα
προαιρετικό κλειδί ελεγκτή. Τόσο η πολιτική έγκρισης όσο και ο ελεγκτής μπορούν
να αλλαχθούν αργότερα (βλ. [Διαμόρφωση ελεγκτή](#configure-an-auditor))· μόνο η
παρουσία της ίδιας της επέκτασης είναι σταθερή κατά τη δημιουργία.

<CodeTabs>

```terminal !! title="create-confidential-mint.sh"
$ spl-token --program-id TokenzQdBNbLqP5VEhdkAS6EPFLC1PHnBqCXEpPxuEb create-token --enable-confidential-transfers auto
```

```rust !! title="create-confidential-mint.rs"
use spl_token_client::token::ExtensionInitializationParams;

let extensions = vec![ExtensionInitializationParams::ConfidentialTransferMint {
    authority: Some(authority.pubkey().into()),
    auto_approve_new_accounts: true, // false for a manual approve policy
    auditor_elgamal_pubkey: None,    // Some(pubkey) to set a global auditor
}];

token
    .create_mint(&mint_authority, freeze_authority.as_ref(), extensions, &[&mint_keypair])
    .await?;
```

```ts !! title="create-confidential-mint.ts"
import { getCreateAccountInstruction } from "@solana-program/system";
import {
  extension,
  getMintSize,
  getInitializeConfidentialTransferMintInstruction,
  getInitializeMintInstruction,
  TOKEN_2022_PROGRAM_ADDRESS
} from "@solana-program/token-2022";

// Size the mint account to include the confidential transfer extension.
const space = BigInt(
  getMintSize([
    extension("ConfidentialTransferMint", {
      authority: authority.address,
      autoApproveNewAccounts: true, // false for a manual approve policy
      auditorElgamalPubkey: null // an ElGamal pubkey Address to set an auditor
    })
  ])
);
const rent = await rpc.getMinimumBalanceForRentExemption(space).send();

// Create the account, initialize the extension, then initialize the mint, in one
// transaction. The extension instruction must come before InitializeMint.
const instructions = [
  getCreateAccountInstruction({
    payer,
    newAccount: mint, // mint keypair signer
    lamports: rent,
    space,
    programAddress: TOKEN_2022_PROGRAM_ADDRESS
  }),
  getInitializeConfidentialTransferMintInstruction({
    mint: mint.address,
    authority: authority.address,
    autoApproveNewAccounts: true,
    auditorElgamalPubkey: null
  }),
  getInitializeMintInstruction({
    mint: mint.address,
    decimals,
    mintAuthority: mintAuthority.address,
    freezeAuthority: null
  })
];
// Sign with the payer and mint keypair, then send.
```

## Διαμόρφωση ελεγκτή

Ένας global ελεγκτής είναι ένα ElGamal pubkey αποθηκευμένο στο mint. Όταν
οριστεί, κάθε εμπιστευτική μεταφορά κρυπτογραφεί επιπλέον το ποσό της με αυτό το
κλειδί, έτσι ώστε όποιος κατέχει το αντίστοιχο μυστικό κλειδί να μπορεί να
αποκρυπτογραφεί όλα τα ποσά μεταφοράς για το mint. Έτσι οι εμπιστευτικές
μεταφορές παραμένουν συμβατές με τις απαιτήσεις ελέγχου και συμμόρφωσης: το
κοινό δεν βλέπει τίποτα, ο ελεγκτής βλέπει τα πάντα.

Η αρχή εμπιστευτικής μεταφοράς μπορεί να ορίσει, να αλλάξει ή να αφαιρέσει τον
ελεγκτή ανά πάσα στιγμή. Η ίδια λειτουργία ενημερώνει επίσης την πολιτική
έγκρισης. Στο CLI, το κλειδί ελεγκτή είναι μια κωδικοποίηση base64 ενός δημόσιου
κλειδιού ElGamal· περάστε `--auditor-pubkey none` για να το αφαιρέσετε και
`--approve-policy auto|manual` για να αλλάξετε την πολιτική.

Η εναλλαγή επηρεάζει μόνο τις μελλοντικές μεταφορές. Τα ποσά σε συναλλαγές που
είναι ήδη καταχωρημένες στο blockchain παραμένουν κρυπτογραφημένα με το κλειδί
ελεγκτή που ήταν ενεργό κατά την εκτέλεσή τους, οπότε διατηρήστε τα παλιά
κλειδιά ελεγκτή εάν χρειαστεί να αποκρυπτογραφήσετε ιστορική δραστηριότητα.

<CodeTabs>

```terminal !! title="update-confidential-settings.sh"
$ spl-token update-confidential-transfer-settings <MINT_PUBKEY> --auditor-pubkey <AUDITOR_ELGAMAL_PUBKEY>
```

```rust !! title="update-confidential-settings.rs"
token
    .confidential_transfer_update_mint(
        &authority,
        true,                         // auto_approve_new_account
        Some(auditor_elgamal_pubkey), // None to clear the auditor
        &[&authority_keypair],
    )
    .await?;
```

```ts !! title="update-confidential-settings.ts"
import { getUpdateConfidentialTransferMintInstruction } from "@solana-program/token-2022";

const ix = getUpdateConfidentialTransferMintInstruction({
  mint,
  authority, // confidential transfer authority (signer)
  autoApproveNewAccounts: true,
  auditorElgamalPubkey // an ElGamal pubkey Address, or null to clear
});
```

</CodeTabs>

<Callout type="warn">
  Το μυστικό κλειδί του ελεγκτή μπορεί να αποκρυπτογραφήσει κάθε ποσό μεταφοράς
  για το mint. Φυλάξτε το με την ίδια αυστηρότητα όπως ένα κλειδί υπογραφής και
  προγραμματίστε την εναλλαγή του. Ο ορισμός του ελεγκτή σε `None` απενεργοποιεί
  την ορατότητα ποσών για όλους εκτός από τους ίδιους τους κατόχους λογαριασμών.
</Callout>

## Έγκριση λογαριασμών (χειροκίνητη πολιτική)

Με μια χειροκίνητη πολιτική έγκρισης, ένας λογαριασμός που έχει διαμορφωθεί για
εμπιστευτικές μεταφορές δεν μπορεί να πραγματοποιήσει εμπιστευτικές συναλλαγές
έως ότου η αρχή εμπιστευτικής μεταφοράς τον εγκρίνει. Αυτό παρέχει στους εκδότες
μια πύλη για συμμετέχοντες σε allowlist ή με επαλήθευση KYC. Το CLI δεν παρέχει
εντολή έγκρισης, οπότε η έγκριση γίνεται μέσω ενός client.

<CodeTabs>

```rust !! title="approve-account.rs"
token
    .confidential_transfer_approve_account(
        &token_account,
        &authority,
        &[&authority_keypair],
    )
    .await?;
```

```ts !! title="approve-account.ts"
import { getApproveConfidentialTransferAccountInstruction } from "@solana-program/token-2022";

const ix = getApproveConfidentialTransferAccountInstruction({
  token, // the token account to approve
  mint,
  authority // confidential transfer authority (signer)
});
```

</CodeTabs>

## Τέλη εμπιστευτικής μεταφοράς

Εάν το mint σας χρεώνει [τέλος μεταφοράς](/docs/tokens/extensions/transfer-fees)
και οι μεταφορές είναι εμπιστευτικές, το τέλος πρέπει επίσης να παρακρατείται με
εμπιστευτικό τρόπο. Η επέκταση `ConfidentialTransferFeeConfig` αναλαμβάνει αυτό
και αρχικοποιείται κατά τη δημιουργία του mint μαζί με τις επεκτάσεις τέλους
μεταφοράς και εμπιστευτικής μεταφοράς.

Τα παρακρατημένα τέλη συσσωρεύονται κρυπτογραφημένα στους λογαριασμούς
παραληπτών, συλλέγονται στο mint και στη συνέχεια αποσύρονται από την αρχή
απόσυρσης παρακρατημένων ποσών. Κάθε ποσό τέλους παραμένει κρυπτογραφημένο καθ'
όλη τη διαδικασία. Τίποτα από αυτά δεν είναι προσβάσιμο μέσω του CLI. Το μυστικό
κλειδί ElGamal της αρχής απόσυρσης παρακρατημένων ποσών μπορεί να
αποκρυπτογραφήσει παρακρατημένα ποσά τελών, τα οποία σε συνδυασμό με τις
δημόσιες παραμέτρους τελών μπορούν να αποκαλύψουν πληροφορίες σχετικά με τα ποσά
μεταφοράς, επομένως αντιμετωπίστε αυτό το κλειδί ως ευαίσθητο.

### Αρχικοποίηση της ρύθμισης χρεώσεων

Συμπεριλάβετε αυτό μαζί με το `ConfidentialTransferMint` και τη ρύθμιση χρέωσης
μεταφοράς στην ίδια δημιουργία mint.

<CodeTabs>

```rust !! title="init-confidential-fee.rs"
use spl_token_client::token::ExtensionInitializationParams;

ExtensionInitializationParams::ConfidentialTransferFeeConfig {
    authority: Some(authority.pubkey().into()),
    withdraw_withheld_authority_elgamal_pubkey: withdraw_withheld_elgamal_pubkey,
};
```

```ts !! title="init-confidential-fee.ts"
import { getInitializeConfidentialTransferFeeInstruction } from "@solana-program/token-2022";

const ix = getInitializeConfidentialTransferFeeInstruction({
  mint,
  authority, // authority allowed to change the withdraw withheld ElGamal key
  withdrawWithheldAuthorityElGamalPubkey // ElGamal pubkey Address
});
```

</CodeTabs>

### Συλλογή και ανάληψη παρακρατηθέντων χρεώσεων

Η συλλογή μετακινεί τις κρυπτογραφημένες παρακρατηθείσες χρεώσεις από τους
λογαριασμούς στο mint· η ανάληψη τις μεταφέρει έξω από το mint σε έναν
επιλεγμένο λογαριασμό. Εμπλέκονται δύο αρχές, και κάθε μία μπορεί να διαφέρει
από την αρχή mint:

- Η **αρχή χρέωσης εμπιστευτικής μεταφοράς** (το `authority` που ορίζεται στο
  `ConfidentialTransferFeeConfig`) ενεργοποιεί ή απενεργοποιεί τη συλλογή.
- Η **αρχή ανάληψης παρακρατηθέντων** (από το `TransferFeeConfig` της επέκτασης
  χρέωσης μεταφοράς) αναλαμβάνει τις συλλεγμένες χρεώσεις από το mint.

Οι αναλήψεις απαιτούν απόδειξη ισότητας και εύρους, που παρέχεται ενσωματωμένα ή
επαληθεύεται σε λογαριασμούς κατάστασης περιβάλλοντος.

<CodeTabs>

```rust !! title="harvest-withdraw-fees.rs"
// Permissionless: move withheld fees from accounts into the mint.
token
    .confidential_transfer_harvest_withheld_tokens_to_mint(&[&source_account])
    .await?;

// Withdraw withheld fees from the mint (requires the withdraw withheld authority).
token
    .confidential_transfer_withdraw_withheld_tokens_from_mint(
        &destination_account,
        &withdraw_withheld_authority,
        None, // proof context state account, supplied inline if None
        None, // withheld tokens info, fetched if None
        &withdraw_withheld_elgamal_keypair,
        &destination_elgamal_pubkey,
        &new_decryptable_available_balance,
        &[&withdraw_withheld_authority_keypair],
    )
    .await?;
```

```ts !! title="harvest-withdraw-fees.ts"
import {
  getEnableHarvestToMintInstruction,
  getHarvestWithheldTokensToMintForConfidentialTransferFeeInstruction
} from "@solana-program/token-2022";

// Allow accounts to harvest their withheld fees to the mint, signed by the
// confidential transfer fee authority.
const enableIx = getEnableHarvestToMintInstruction({ mint, authority });

// Permissionless: move withheld fees from accounts into the mint.
const harvestIx =
  getHarvestWithheldTokensToMintForConfidentialTransferFeeInstruction({
    mint,
    sources: [sourceAccount]
  });
```

</CodeTabs>

Στο JS client, η ανάληψη των συλλεγμένων χρεώσεων από το mint
(`getWithdrawWithheldTokensFromMintForConfidentialTransferFeeInstruction`)
απαιτεί επιπλέον απόδειξη ισότητας και εύρους επαληθευμένη σε λογαριασμούς
κατάστασης περιβάλλοντος, επομένως ακολουθεί το ίδιο μοτίβο λογαριασμού
απόδειξης με μια εμπιστευτική μεταφορά.

## Εμπιστευτική έκδοση και καύση

Η επέκταση `ConfidentialMintBurn` επιτρέπει στην αρχή mint να εκδίδει και να
καίει προσφορά απευθείας σε εμπιστευτικά υπόλοιπα, διατηρώντας την
κρυπτογραφημένη τη συνολική προσφορά. Ένα mint με αυτήν την επέκταση
απενεργοποιεί τη δημόσια διαδρομή κατάθεσης και ανάληψης, καθώς τα tokens
υπάρχουν αποκλειστικά σε εμπιστευτική μορφή. Δείτε την
[τεκμηρίωση πρωτοκόλλου](https://www.solana-program.com/docs/confidential-balances)
για το πλήρες μοντέλο.

<Callout type="info">
  Η εμπιστευτική έκδοση/καύση είναι πιο εύκολη μέσω του Rust `spl-token-client`,
  ο οποίος δημιουργεί τις απαιτούμενες αποδείξεις και ακολουθεί τις συναλλαγές
  για εσάς. Το `@solana-program/token-2022` JS client περιλαμβάνει τους
  κατασκευαστές εντολών χαμηλού επιπέδου (`getConfidentialMintInstruction`,
  `getConfidentialBurnInstruction` και άλλους) αλλά όχι βοηθό υψηλού επιπέδου
  για τη δημιουργία αποδείξεων, και δεν υπάρχουν εντολές CLI, επομένως τα
  παρακάτω παραδείγματα είναι μόνο για Rust.
</Callout>

Αρχικοποιήστε την επέκταση κατά τη δημιουργία του mint, στη συνέχεια κόψτε,
κάψτε και συγχωνεύστε την προμήθεια με την πάροδο του χρόνου. Το minting εκδίδει
ένα κρυπτογραφημένο ποσό στο εμπιστευτικό υπόλοιπο ενός παραλήπτη· το burning
αφαιρεί ένα κρυπτογραφημένο ποσό σε μια εκκρεμή διαδικασία burn που αργότερα
ενσωματώνεται στην προμήθεια. Και οι δύο λειτουργίες παράγουν αποδείξεις όπως
μια εμπιστευτική μεταφορά.

<CodeTabs>

```rust !! title="confidential-mint-burn.rs"
use spl_token_client::token::ExtensionInitializationParams;

// 1. Initialize at creation (alongside ConfidentialTransferMint).
ExtensionInitializationParams::ConfidentialMintBurn {
    supply_elgamal_pubkey, // encrypts the confidential supply
    decryptable_supply,    // AES ciphertext of the initial supply (zero)
};

// 2. Mint an encrypted amount into a recipient's confidential balance.
token
    .confidential_transfer_mint(
        &mint_authority,
        &destination_account,
        None, // equality proof account
        None, // ciphertext validity proof account
        None, // range proof account
        mint_amount,
        &supply_elgamal_keypair,
        &destination_elgamal_pubkey,
        auditor_elgamal_pubkey, // Option
        &supply_aes_key,
        None, // supply account info, fetched if None
        &[&mint_authority_keypair],
    )
    .await?;

// 3. Burn an encrypted amount from a holder's confidential balance into the
//    mint's pending burn. Generates proofs like a confidential transfer.
token
    .confidential_transfer_burn(
        &owner,
        &source_account,
        None, // equality proof account
        None, // ciphertext validity proof account
        None, // range proof account
        burn_amount,
        &source_elgamal_keypair,
        &supply_elgamal_pubkey,
        auditor_elgamal_pubkey, // Option
        &source_aes_key,
        None, // burn account info, fetched if None
        &[&owner_keypair],
    )
    .await?;

// 4. Fold the accumulated pending burn into the confidential supply.
token
    .confidential_transfer_apply_pending_burn(&mint_authority, &[&mint_authority_keypair])
    .await?;
```

</CodeTabs>

Εναλλάξτε το κλειδί κρυπτογράφησης προμήθειας με
`confidential_transfer_rotate_supply_elgamal_pubkey` (η εκκρεμής διαδικασία burn
πρέπει να είναι πρώτα μηδέν), και ανανεώστε το αναγνώσιμο κείμενο κρυπτογράφησης
προμήθειας με `confidential_transfer_update_decrypt_supply`.

## Επιχειρησιακές και κανονιστικές εκτιμήσεις

- **Φύλαξη κλειδιού ελεγκτή.** Εάν ορίσετε έναν ελεγκτή, το μυστικό κλειδί του
  ελεγκτή είναι ένα κλειδί αποκρυπτογράφησης υψηλής αξίας. Αποθηκεύστε και
  εναλλάξτε το προσεκτικά, και αποφασίστε ποιος εντός του οργανισμού σας (ή
  ποιος ρυθμιστής) το κατέχει.
- **Στάση συμμόρφωσης.** Ο έλεγχος διευθύνσεων και η ανάλυση γράφου
  αντισυμβαλλομένων συνεχίζουν να λειτουργούν επειδή οι διευθύνσεις παραμένουν
  δημόσιες. Η παρακολούθηση βάσει ποσών εξαρτάται από το κλειδί ελεγκτή ή από
  την επιλεκτική αποκάλυψη από τους κατόχους λογαριασμών. Αποφασίστε την
  προσέγγισή σας πριν από την έναρξη.
- **Ενσωμάτωση κατόχων.** Η διαμόρφωση ενός εμπιστευτικού λογαριασμού απαιτεί
  την υπογραφή του κατόχου. Για να παρέχετε λογαριασμούς στους χρήστες ομαλά,
  ζητήστε τους να καταχωρίσουν ένα κλειδί ElGamal μία φορά και να
  χρησιμοποιήσουν τη διαδρομή μητρώου, που περιγράφεται στον
  [Οδηγό Ενσωμάτωσης](/docs/tokens/extensions/confidential-transfer/integration-guide#creating-and-configuring-accounts).
- **Αριθμός συναλλαγών.** Μια εμπιστευτική μεταφορά καλύπτει επί του παρόντος
  μερικές εξαρτημένες συναλλαγές επειδή οι αποδείξεις υπερβαίνουν το τρέχον όριο
  μεγέθους συναλλαγής. Η μορφή συναλλαγής v1 (που κυκλοφορεί με το Agave v4.2)
  αυξάνει αυτό το όριο και αναμένεται να επιτρέπει μία μόνο συναλλαγή στην
  αλυσίδα.
