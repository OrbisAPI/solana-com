**توفر سولانا Keychain واجهة موحدة لتوقيع معاملات سولانا عبر أنظمة متعددة لإدارة
المفاتيح.** طوِّر محلياً باستخدام مفتاح في الذاكرة، ثم انتقل إلى إدارة مفاتيح
المؤسسات، أو وحدات HSM السحابية، أو خدمات المحافظ المُدارة في بيئة الإنتاج — دون
الحاجة إلى إعادة كتابة كود التوقيع الخاص بك.

### لماذا Keychain؟

- **واجهة موحدة**: سمة `SolanaSigner` واحدة تعمل عبر جميع الأنظمة الخلفية
- **تبديل الأنظمة الخلفية**: غيِّر مزودي إدارة المفاتيح من خلال الإعدادات، لا
  الكود
- **تجريد بدون تكلفة**: تتضمن أعلام الميزات فقط ما تحتاجه
- **مُدقَّق**: تمت مراجعته أمنياً بواسطة [Accretion](https://accretion.xyz)

### البنية المعمارية

- **اللغات**: Rust + TypeScript، بتكافؤ كامل
- **السمة**: واجهة `SolanaSigner` الموحدة
- **الأنظمة الخلفية**: Memory، Vault، AWS KMS، GCP KMS، Privy، Turnkey،
  Fireblocks، CDP، Crossmint، Dfns، Openfort، Para، Utila
- **التوافق**: متوافق مع `@solana/kit` و `@solana/signers` (TypeScript) | متوافق
  مع `solana-sdk` و `solana-sdk-v3` (Rust)

### الخلفيات المدعومة

تمتد الأنظمة الخلفية لتشمل التطوير المحلي، وإدارة المفاتيح ذاتية الاستضافة
والسحابية، وخدمات المحافظ المُدارة أو MPC. راجع
[اختيار نظام خلفي](/docs/tools/keychain/choosing-a-backend) لمقارنة نماذج
الحضانة واختيار المناسب منها.

| النظام الخلفي   | حالة الاستخدام                 | Rust | TypeScript |
| --------------- | ------------------------------ | ---- | ---------- |
| Memory          | التطوير والاختبار              | ✓    | ✓          |
| HashiCorp Vault | إدارة المفاتيح ذاتية الاستضافة | ✓    | ✓          |
| AWS KMS         | سحابي أصلي (AWS)               | ✓    | ✓          |
| GCP KMS         | سحابي أصلي (GCP)               | ✓    | ✓          |
| Privy           | محافظ مدمجة                    | ✓    | ✓          |
| Turnkey         | إدارة المفاتيح غير الحافظة     | ✓    | ✓          |
| Fireblocks      | حضانة مؤسسية                   | ✓    | ✓          |
| CDP             | منصة مطوري Coinbase            | ✓    | ✓          |
| Crossmint       | محافظ Crossmint المُدارة       | ✓    | ✓          |
| Dfns            | بنية تحتية لمحافظ Dfns         | ✓    | ✓          |
| Openfort        | محافظ خلفية Openfort           | ✓    | ✓          |
| Para            | محافظ Para MPC                 | ✓    | ✓          |
| Utila           | حضانة Utila MPC                | ✓    | ✓          |

## البداية السريعة

### Rust

ثبّت حزمة Rust:

```bash
cargo add solana-keychain
```

الاستخدام الأساسي:

```rust
use solana_keychain::{Signer, SolanaSigner};

// Create a signer from any backend
let signer = Signer::from_memory("base58_private_key")?;

// All signers share the same interface
let pubkey = signer.pubkey();
let signature = signer.sign_transaction(&mut tx).await?;
```

- [دليل Rust](/docs/tools/keychain/getting-started/rust) - التثبيت الكامل وإعداد
  الخلفية
- [Crates.io](https://crates.io/crates/solana-keychain) - حزمة Rust

### TypeScript

ثبّت حزمة TypeScript:

```bash
pnpm add @solana/keychain
```

الاستخدام الأساسي:

```typescript
import { createKeychainSigner } from "@solana/keychain";
import { signTransactionWithSigners } from "@solana/signers";

// Create any signer via the unified factory
const signer = await createKeychainSigner({
  backend: "vault",
  vaultAddr: "https://vault.example.com:8200",
  vaultToken: "hvs.xxxxx",
  keyName: "my-solana-key",
  publicKey: "base58_public_key"
});

// Sign an already-compiled transaction
const signedTx = await signTransactionWithSigners(
  [signer],
  compiledTransaction
);
```

- [دليل TypeScript](/docs/tools/keychain/getting-started/typescript) - حزم
  `@solana/keychain`
- [حزمة npm](https://www.npmjs.com/package/@solana/keychain) - حزمة npm
